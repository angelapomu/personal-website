# Angela 徐晓萌 · 个人作品集

AI 产品作品集，展示从用户研究、产品设计到 AI 实现与验证的工作。

首页保留现有 Figma 项目卡片结构，使用新提供的 Angela 页面灰黑亮粉色板。首屏以大字报排版展示「做让用户自己 / 想回来的AI产品」，标题和介绍整体在 1280px 宽的区域内居中，两行按内容宽度缩放，「自己」使用亮粉色高光，「想回来」恢复近黑；保留文字排斥与弹回动效。详情可返回首页原来的浏览位置。

作品区使用「主要项目」和「早期探索」两组中文标题行，移除旧的大标题、年份、说明和标题上方细线，保留首屏与作品区之间的深色分割线。首屏底部使用居中的「下滑查看我的作品」小字与细长下箭头，只有箭头浮动，去掉粉色圆底和按钮造型。页脚使用相同炭灰色，文案为「感谢观看！欢迎联系」。AIPM CAPABILITIES 使用柔和炭灰底 `#2B2D31` 和灰白文字，顶部「关于我」直接定位到该区。

作品区采用已确认的 A「轻巧画廊」：内容最大宽度 1120px，双列主海报比例 1.6，宽屏时约 338px 高；早期探索海报比例 1.9，约 284px 高。平板改单列并限制为 540px 宽，手机保留较高比例以确保预览清晰。项目名前不显示编号；名称、说明和标签左对齐。项目名 30–40px，说明/类型 16px，标签 14px。手机截图重新排位，在较矮的海报内保持完整。

卡片第一次进入视野时上移 28px 并淡入，持续 600ms；同排右卡延后 100ms，单列没有延后。返回详情后不重播；减少动态效果、键盘聚焦和不支持动画的浏览器均直接显示内容。现有 `?motion=on` 预览会显式启用卡片入场。可运行 `node tests/project-cards.cjs` 检查这些状态。

## 预览

通过任意静态服务器打开 `index.html` 即可预览，无需安装依赖或构建。新版主页与我吗详情使用 Noto Sans SC 和 IBM Plex Mono；插入的项目预览图保留 Outfit 字体，字体无法加载时使用系统字体。

简历区目前按设计使用模板占位：点击简历缩略图可全屏预览，下载按钮在真实 PDF 补充前保持禁用。

四张项目卡片使用我吗 OhMee、Why Bother、截图词典和 shelter 的真实项目名称、介绍、标签与图片；卡片说明和项目类型使用 16px，所有标签统一为 14px 并支持换行。四个箭头入口连接到各自的完整详情页，图片支持放大和我吗界面切换。shelter 保留黑色预览，定位为早期手绘探索。

卡片结构及首页 Hero 以外的文字、能力区、关于区沿用现有版本。其余保留的模板履历和联系方式用于当前 UI 评审，不代表已核实的个人资料。

首页和我吗详情共用 36px 高的浅灰导航栏：Angela. 徐晓萌 / 作品 / 关于我 / 简历，使用深色文字和粉色选中标记。章节吸顶与页面跳转偏移同步适配。其余详情保留原有配色。

我吗详情页保留现有排版，使用浅灰开场、灰白阅读区和近黑复盘区，亮粉色用于重点与选中状态。双屏截图、产品体验、研究证据和结果复盘串起案例，重写体验可以切换现有产品截图中的原话与重写结果；技术实现和补充截图可展开阅读，保留所有原有指标与图片素材。其余三个项目详情沿用现有版本。

首屏字形响应鼠标与触摸，离开后弹回；不拦截页面滚动。离屏或切换详情时停止动画。默认跟随系统减少动态效果设置；`?motion=on#top` 用于明确启用动效的设计预览，不修改系统设置。可用 `node tests/spring-motion.cjs` 检查这组交互状态。色板：浅灰 `#E9E9E6`、近黑 `#15171A`、亮粉 `#FF2E93`、灰白 `#F6F6F3`；Why Bother 的项目画面保留橘色 `#EF5A26`。

在 960px 及以下，章节目录收为「当前章节 + 展开菜单」，点击可见全部章节，选中后收起并定位正文；滚动时更新当前章节。支持 Escape、点击外部或移出键盘焦点关闭，切换屏幕宽度时保持可见焦点。桌面保留横排目录。

- `index.html`：页面、响应式样式、项目详情及交互。
- `angela-palette.css`：主页与我吗详情的灰粉配色、弹性首屏布局。
- `spring-hero.js`：首屏文字排斥与弹回动效。
- `project-cards.js`：项目卡片一次性的上移淡入、焦点与减少动态效果处理。
- `images/`：页面引用的产品截图、研究材料与插画。
- `AGENTS.md`：后续修改的协作规则。

联系方式与简历尚待补充。

## 改版流程

每次改版均从最新 `main` 创建独立分支，推送后提交 PR，说明改动与验证结果；不直接推送改版到 `main`。本次以当前评审版本 `7599302` 为 UI 基线，该版本尚未合入 main，因此 PR 同时包含它与初始 main 之间的差异。
