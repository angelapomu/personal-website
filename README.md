# Angela 徐晓萌 · 个人作品集

AI 产品作品集，展示从用户研究、产品设计到 AI 实现与验证的工作。

首页重点呈现「我吗 OhMee」和「Why Bother」。截图词典作为个人工具，shelter 作为以手绘为主的早期探索。每个项目可进入详情，再返回首页原来的位置。

## 预览

用浏览器打开 `index.html` 即可预览，无需安装依赖或构建。主页沿用提供的 Figma 页面，使用 Space Grotesk、DM Mono 和 Noto Sans SC；项目卡片保留 Outfit 字体，字体无法加载时使用系统字体。

简历区目前按设计使用版式占位：点击“预览简历”可查看占位弹窗，下载按钮在真实 PDF 补充前保持禁用。

首页采用 Figma 源码中的蓝色 Hero、双列作品、能力、关于、橘色简历区与页脚，保持原有长页结构。四个作品接入既有项目卡片与详情，支持截图放大、我吗界面切换，以及返回原浏览位置。照片与正式 PDF 目前均为明确占位；模板中的虚构姓名、履历和邮箱已替换。

- `index.html`：页面、响应式样式、项目详情及交互。
- `images/`：页面引用的产品截图、研究材料与插画。
- `AGENTS.md`：后续修改的协作规则。

联系方式与简历尚待补充。

## 改版流程

当前版本是仓库的初始基线。之后每次改版均从最新 `main` 创建独立分支，推送后提交 PR，说明改动与验证结果；不直接推送改版到 `main`。
