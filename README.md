# Angela 徐晓萌 · 个人作品集

AI 产品作品集，展示从用户研究、产品设计到 AI 实现与验证的工作。

首页按提供的 Figma 源码展示，四个预览区依次接入我吗、Why Bother、截图词典和 shelter 的图片与详情页。详情可返回首页原来的浏览位置。

## 预览

用浏览器打开 `index.html` 即可预览，无需安装依赖或构建。主页使用原 Figma 页面的 Space Grotesk、DM Mono 和 Noto Sans SC；插入的项目预览图保留 Outfit 字体，字体无法加载时使用系统字体。

简历区目前按设计使用模板占位：点击简历缩略图可全屏预览，下载按钮在真实 PDF 补充前保持禁用。

按用户最新要求，主页仅替换四个项目预览区的图片；卡片结构、标题、介绍、标签、能力区、关于区、配色和排版均沿用 Figma 原稿。保留的模板姓名、项目名称、履历和联系方式用于当前 UI 评审，不代表已核实的个人资料。项目图片支持放大和我吗界面切换，四个箭头入口连接到原有详情页。

- `index.html`：页面、响应式样式、项目详情及交互。
- `images/`：页面引用的产品截图、研究材料与插画。
- `AGENTS.md`：后续修改的协作规则。

联系方式与简历尚待补充。

## 改版流程

当前版本是仓库的初始基线。之后每次改版均从最新 `main` 创建独立分支，推送后提交 PR，说明改动与验证结果；不直接推送改版到 `main`。
