# Angela 徐晓萌 · 个人作品集

AI 产品作品集，展示从用户研究、产品设计到 AI 实现与验证的工作。

首页按提供的 Figma 源码展示，四个预览区依次接入我吗、Why Bother、截图词典和 shelter 的图片与详情页。详情可返回首页原来的浏览位置。

## 预览

用浏览器打开 `index.html` 即可预览，无需安装依赖或构建。主页使用原 Figma 页面的 Space Grotesk、DM Mono 和 Noto Sans SC；插入的项目预览图保留 Outfit 字体，字体无法加载时使用系统字体。

简历区目前按设计使用模板占位：点击简历缩略图可全屏预览，下载按钮在真实 PDF 补充前保持禁用。

四张项目卡片使用我吗 OhMee、Why Bother、截图词典和 shelter 的真实项目名称、介绍、标签与图片；所有卡片标签统一为原 MORI 标签的字号和内边距。四个箭头入口连接到各自的完整详情页，图片支持放大和我吗界面切换。shelter 保留黑色预览，定位为早期手绘探索。

卡片结构及其余首页文字、能力区、关于区、配色和排版沿用 Figma 原稿。保留的模板姓名、履历和联系方式用于当前 UI 评审，不代表已核实的个人资料。

我吗详情页使用橘色开场与结尾、米白正文，蓝色用于按钮和选中状态。双屏截图、产品体验、研究证据和结果复盘串起案例，重写体验可以切换现有产品截图中的原话与重写结果；技术实现和补充截图可展开阅读，保留所有原有指标与图片素材。其余三个项目详情沿用现有版本。

在 960px 及以下，章节目录收为「当前章节 + 展开菜单」，点击可见全部章节，选中后收起并定位正文；滚动时更新当前章节。支持 Escape、点击外部或移出键盘焦点关闭，切换屏幕宽度时保持可见焦点。桌面保留横排目录。

- `index.html`：页面、响应式样式、项目详情及交互。
- `images/`：页面引用的产品截图、研究材料与插画。
- `AGENTS.md`：后续修改的协作规则。

联系方式与简历尚待补充。

## 改版流程

当前版本是仓库的初始基线。之后每次改版均从最新 `main` 创建独立分支，推送后提交 PR，说明改动与验证结果；不直接推送改版到 `main`。
